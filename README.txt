CONTENTFLOW CMS - COMPLETE FRONTEND PROJECT

HOW TO RUN
1. Extract CMS_Full_Project.zip.
2. Open the folder.
3. Double-click index.html.
4. Use the demo Admin account or create a new User account.

TECHNOLOGY
HTML5
CSS3
JavaScript
Browser Local Storage

IMPORTANT
This is a frontend-only academic prototype. Authentication is implemented
for demonstration and credentials are stored in browser Local Storage.
A production CMS should use a backend, database, secure password hashing,
sessions/JWT, server-side authorization and proper validation.
